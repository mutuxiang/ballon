自拍漫画皮肤 · 本地版

基于从 GitHub 全新克隆的 main：64efc7103ead45c47c6be8f593d15df874640213。
功能分支：feature/selfie-comic-skin。主分支不包含本次功能改动。

启动 npm run dev -- --port 5176，打开 http://127.0.0.1:5176/。
点击右侧底部「自拍漫画皮肤」，开启相机或选择照片。
对齐取景：头发与脸在上半格，衣服在下半格。点击「生成漫画皮肤」。
左侧保留原照片，右侧展示重新绘制后的漫画皮肤。可校对发型、表情、眼镜、服装与配色。
点击「穿到小人上」，头部、发顶、服装和手臂统一配色，贴图随动画变形。
当前皮肤可通过原有下载按钮导出 GLB。切换原有服装/表情或「恢复原有皮肤」可退出。

实现方式：本地颜色聚类与区域特征估计 → 可编辑的特征描述 → 统一笔触的矢量形状重绘 → 头部/衣服分别环绕 UV 贴图。
已移除三角马赛克滤镜。成品贴图不复制照片像素，不带入原图背景、阴影与碎色纹理。
这是本地规则式漫画重绘，未接入 AI 图生图或精确人像识别；自动估计可能不准，可通过特征校对修正。
照片仅在浏览器内存处理，不上传。关闭页面后不保存皮肤。

验证：构建、原有测试、相机截帧测试、颜色/特征提取测试；Edge 浏览器验证上传、生成、特征校对、应用、动画变形与恢复。
浏览器测试使用合成图像，未使用真实摄像头。
