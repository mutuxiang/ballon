# 充气打工人 · Air Worker

光滑、短胖的充气角色，使用分区色块表现上班族：深色中分头发、桃肤色的脸和圆手、浅蓝衬衫、白领口、深灰领带、藏蓝裤身。脸部采用参考图中的半眯眼、弯鼻子、嘟嘴表情。

## 交付

身体主轴约 4.9 米、直径约 1.3 米，手臂外伸约 1 米。身体和手臂表面光滑饱满，无细碎波纹。网页预览采用三渲二材质（四级明暗、分区高光、细描边）。`toon.js` 提供可复用的 Three.js 材质设置。GLB 保留光滑几何、色块、循环动画与通用 PBR 材质；导入其他软件后，需要在该软件中设置 toon 材质才能复现相同光影，glTF 不保存本预览的自定义着色器。

- `public/air-dancer.glb`：包含材质和 8 秒循环形态动画的通用 GLB 模型，Y 轴向上，单位米。可导入 Blender、Three.js 等支持 glTF morph target 动画的工具。
- `dist/`：完整离线预览（请通过本地 HTTP 服务打开）；无外部 CDN、字体或图片依赖。
- `model.mjs`：可编辑的程序化建模及动画源代码。

## 使用

已安装 Node.js 的电脑可双击 `start-preview.cmd`，或运行 `node preview.cjs` 后打开 `http://127.0.0.1:5187/`。请通过本地 HTTP 服务打开，不要直接双击 `dist/index.html`。

开发：运行 `npm install`，然后 `npm run dev`，打开终端显示的本地地址。拖动旋转、滚轮缩放，支持暂停和速度调节。

`npm run model` 重新生成 GLB；`npm run build` 构建预览。

动画名 `Inflate_Sway_Fold_Loop`，8 秒，64 个变形采样，线性插值与首尾循环。底座固定，身体鼓胀、左右塌腰、上身滞后与回弹、短臂甩动；头发、表情和衣服一起变形。动画是程序化变形模拟气流效果，不是流体或布料物理解算。GLB 使用形态键而非骨骼；可在 Blender 导入后编辑形态键，或修改 `model.mjs` 后重新导出。
