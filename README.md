# 充气打工人 · Air Worker

## 表情皮肤
新增独立「随动作切换」表情模式，可搭配任意衣服。依据实际头部高度、气压、倾斜、移动速度及上下运动切换：躺平→淡定直视，泄气下坠→嘟嘴营业，充气抬头→星星眼，弯折撑住→勉强露齿，大幅摇摆→闪亮露齿，上扬回弹→微笑营业，轻摇→淡定摸鱼，站稳→自信微笑。自动模式不会选中原版；每次保持至少 0.85 秒，新运动状态持续 0.22 秒后再切换。暂停冻结切换，调速同步影响判断。点击任意表情会恢复手动；关闭自动时恢复之前的手动选择。刷新后记住模式，导出包含当前实际显示的表情。

新增「青绿渐变」衣服风格：以粉蓝青绿为基础，仅脸部、颈部及露出的手臂/手掌皮肤从上向下渐变为现有青绿色（#629FA1）。头部实际世界高度越低，渐变越深、向下覆盖的范围越大；接近最高位置时完全恢复柔玫粉。颜色按皮肤本身的位置分布，随身体弯曲，不受相机缩放旋转影响。衣服、头发、五官描边和眼白不染色；鼻子内部及眼皮露出下方真实皮肤的渐变。暂停会保持当前颜色，GLB 导出包含当前姿态下的静态渐变。

新增「漫画动感」衣服风格：沿用柔玫粉、浅蓝和青绿配色，在人物后方增加斜向手绘漫画线。线条锚点跟随身体与手臂的实际物理位置，每条线独立改变长度，并以 12 帧/秒重画轻微抖动。暂停时线条同时冻结，速度滑块同时影响动作和重画节奏；旋转视角时保持背景位置，人物会遮住线条。切换其他服装即隐藏漫画线。背景效果属于页面表现，不包含在角色 GLB 导出中。

衣服风格提供「原版衣服」「内部描边」「粉蓝青绿」「漫画动感」「青绿渐变」五个独立选项。粉蓝青绿搭配用户选定的柔玫粉肤色（#F5C2C5）、浅蓝衬衫、青绿裤身、腰线及底座浅蓝饰带；脸部、手臂、鼻子内部、眼皮底色与缩略图同步配色。描边款的领口、衣领、领带及两侧袖口使用统一线宽；线条随物理变形，衣领遮挡领带。切换不改变表情与充气状态，并记住上次选择。导出 GLB 同时包含当前衣服。

右侧「今天用哪张脸？」提供 9 个选项：原版表情，以及按参考图顺序排列的淡定摸鱼、嘟嘴营业、微笑营业、星星眼、闪亮露齿、勉强露齿、自信微笑、淡定直视。淡定直视采用不相连的窄椭圆眼眶、居中瞳孔和两侧眼白，搭配参考图的平嘴。原版使用项目最初的五官网格；参考表情按原图轮廓绘制，半睁眼款保留贯穿双眼的连续眼皮线。
面部贴图由 skins.js 本地绘制，无需联网；贴图网格随实时物理变形。切换不重置充气状态或动作，并在浏览器记住上次选择。
「下载当前皮肤模型」导出包含当前表情和当前姿态的静态 GLB；public 中的原始动画 GLB 保持不变。

短胖的充气上班族，保留无打光色块、短手臂和慵懒表情。

## 实时模拟
预览通过 physics.js 的固定 120 Hz 位置约束求解器计算动作：25 个身体节点、两条独立手臂、重力、惯性阻尼、送风推力、随压力变化的弯曲刚度、底部到顶部的压力传输、折弯压力损失、地面接触。相关随机扰动使摆动不再固定循环。

三种状态直接改变送风量。切换不重置位置或速度：没气逐渐软塌，气少支撑较弱，气多恢复鼓胀并摆动。暂停和调速对所有状态有效，底部进度条显示顶部压力。

这是为交互效果设计的简化弹性杆和气压模型，参数为视觉调校，尚未用实物数据标定，不是完整流固耦合或布料求解。极端折叠仍可能自交。

## 交付
- model.mjs：角色几何；预览使用 rest 模式生成静止网格，旧曲线代码仅保留供历史参考。
- arm-mesh.js：每条手臂与手掌使用一张连续网格、共享法线，仅以顶点色区分袖子和皮肤；弯曲方向连续插值。
- physics.js：实时动力学与网格变形。
- toon.js：不受灯光影响的色块。
- silhouette.js：基于整个角色遮罩的屏幕空间外轮廓，保留粗描边，避免膨胀背面在手腕和折弯处露出黑线。描边属于预览效果，不烘焙到 GLB。
- public/air-dancer.glb、air-dancer-low.glb：分别为气多、气少模拟的 6 秒动作采样（不是无缝循环，也不携带实时求解器）。
- public/air-dancer-none.glb：关风后稳定下来的姿态。
- dist/：已构建的预览；GLB 使用 KHR_materials_unlit。

## 运行
npm install 后运行 npm run dev。npm run model 重新采样并导出三个 GLB，npm run build 构建预览。npm test 检查手臂网格连通性、接缝与法线，以及状态切换连续性、关风落地、重新充气与稳定性。

已安装 Node.js 可双击 start-preview.cmd，或 node preview.cjs 后打开 http://127.0.0.1:5187/ 。使用本地 HTTP 服务访问，不能直接双击 dist/index.html。

## Windows 桌宠
双击 start-pet.cmd，或运行 npm run pet。首次使用先 npm install；启动后无需本地网页服务器。透明无边框窗口默认置顶，左键拖动，右键切换气量、表情、服装、暂停和退出。固定正面正交视角，身体与手臂允许三维运动，前后受力较弱，放气更偏向左右倒下。npm run pet:start 直接运行已构建版本。网页预览仍可自由旋转。

## 脚蹬互动
左 A、右 L；按住接通、松开断开。双脚满气、单脚半气、离座没气。桌宠通过全局键盘钩子接收 A/L（不记录其他按键），在其他软件前台时同样响应；普通键盘 A/L 也会触发，可在右键菜单关闭脚蹬控制。网页仅在页面有焦点时响应。单次踩踏带来轻微侧向回弹。屏幕不显示 A/L 控件或文字气泡；倒下时按实际头部速度绘制黑白斜线，落地短暂出现无文字的冲击折线，暂停时冻结。

## 交替蓄力与专注
连续交替踩 A/L（相邻踩下间隔小于 1.5 秒）约 10 次蓄满，长按重复与同侧重复不累计。停顿逐渐退回。蓄满进入 15 秒超级模式，满气与黑白漫画周边排线，当前前台应用窗口去掉边框并铺满所在屏幕，桌宠维持原尺寸；Esc 可随时恢复，也会自动结束。不更改系统通知免打扰设置。倒下时皮肤按高度渐变青绿，仅没气与其他状态切换过程中背后出现漫画斜线；起身恢复肤色。

桌面全屏通过 focus-window.ps1 保存并恢复前台窗口样式与位置，支持 Esc、15 秒结束及正常退出恢复。

专注模式仅叠加 imagegen 生成的黑白漫画周边排线与网点素材，保持原模型、衣服、表情与实时动作。移除金色能量与电光，左右脚使用 A/L。

专注模式表情为 imagegen 生成的透明五官贴图，仅更换五官，不遮盖肤色、不更换模型。退出恢复之前表情；自动表情模式也可正常恢复。

速度线减少为 12 条，沿头部实际运动反方向拖尾，长度随速度变化。专注模式增强气流支撑与抗弯刚度，头后出现放射线。蓄力条采用生图生成的漫画墨线边框与动态排线填充。全屏助手使用独立输入队列，记住最近外部窗口，并恢复原位置、大小与最大化状态。

放射线每 700ms 采样角色周围屏幕明暗，深色背景切换浅线、浅色背景切换深线。采样仅用于亮度计算，不保存或上传屏幕内容。前台铺满使用物理像素 DPI 感知并清除窗口最大化/边框约束，回读实际窗口尺寸供诊断。

速度线保持 45 度，按左右运动方向镜像。漫画蓄力条跟随头顶投影并限制在窗口内；专注入场增加一次约 1.1 秒的放射线扩张、冲击环和网点爆发，随后恢复持续头后光环。

专注入场的扩散环通过独立透明置顶效果窗口覆盖角色所在整个屏幕，约 1.6 秒自动关闭，不抢焦点、不拦截鼠标。速度线仅在没气切换过程且实际下坠时出现，起身不显示。

## 沉浸式游玩：下班保卫战

分支 `feat/immersive-pedal-play` 基于 main 的 `254c50a`。双击 `start-play.cmd`：自动检查并启动本地服务，再打开 http://127.0.0.1:5190/play.html 。已有服务会直接复用，不需要 npm install。启动失败时查看 play-preview-error.log。服务只监听本机，关闭电脑后需要再次运行启动文件。

也可以 `node play-preview.cjs` 启动；`npm run dev` 开发，`npm run build` 同时构建模型页和游玩页。首页提供游玩入口。

玩法参考 Rise Up 的保护、推开障碍和递增难度循环：https://play.google.com/store/apps/details?id=com.riseup.game 。角色沿用仓库原有三维模型和弹性物理；背景改成 imagegen 制作的简洁日系平面高层写字楼，用大色块和少量漫画轮廓表达高度。掉落物是尖铅笔、图钉、纸飞机和 KPI 尖箭头。

### 方向与踩踏是两种输入

- 双脚蹬各有独立 X/Y 两轴（360°方向）和踩下/松开开关。
- 当前鼠标只模拟一只脚蹬，默认左脚；按 Q 可切换模拟侧（界面不显示模拟卡片）。未选中的脚蹬不提供额外自动防护。
- 鼠标在角色全身中心周围全方向移动防护圈，控制范围是半径 220 游戏单位；碰到铅笔、纸飞机即可拨开。
- 点击鼠标模拟一次踩踏，约 0.23 秒强气流窗口可击退图钉和 KPI。按住不会不断重复重击；重物接近时重新踩下才有效。点击也补 1.5% 气量，补气最短间隔 0.22 秒。
- A/L 可以模拟对应脚蹬开关，触屏拖动控制方向、点按踩踏。
- 标准 Gamepad：左、右摇杆分别控制两脚方向，LT/RT 分别踩踏；带 0.12 死区。拔掉手柄恢复鼠标模拟。真实脚蹬尚未连接测试，非标准设备需要适配轴和按钮。

### 必杀技「喘口气」

正常击退 6 件工作后解锁；解锁前踩踏不会积累必杀。解锁后重复踩下任意一只脚蹬 6 次蓄满自动清场，鼠标连续点击即可，同侧重复有效。每次有效蓄力至少间隔 0.15 秒，长按不累加；停顿超过 2 秒蓄力缓慢消退，已解锁资格保留。清场补 20% 气量并保护 1 秒。使用后需重新击退 6 件；清场击退的物品计分但不累积下一次必杀资格。

被击中扣 28% 气量，并有 1.2 秒免伤；身体随气压逐渐软下去，耗尽气量才结束。每件击退得 10 分，每 20 秒升一波。P/Esc 暂停，切换窗口自动暂停并释放脚蹬；支持浏览器全屏与可选合成音效。

### 硬件接口与验证

`window.airWorkerGame.setStick('left', x, y, down)`（right 同理）：x/y 为 [-1,1]，Y 正方向朝屏幕下方，超出单位圆会归一化；两侧互不影响。`setPedal(side, down)` 仅更新开关。也可派发 `CustomEvent('air-worker-pedal', {detail:{side:'left',x:0,y:-1,down:true}})`。`disconnect()` 回到鼠标。暂停/结束不会接受踩踏。

素材为 public/office-towers.png 与 public/work-hazards.png，均由 imagegen 生成。office-plaza.png 是保留的旧背景，不再被游玩页引用。

自动测试覆盖漏气保护、360°方向、双侧独立输入、重物踩踏、击退解锁、同侧连踩清场、长按不刷蓄力、清场不能自循环解锁，以及重置。生产构建通过。当前自动浏览器权限检查拒绝访问本地地址，未完成画面、触屏、全屏和实物脚蹬验证。

### 四面来袭与表情反馈

攻击从屏幕上、右、下、左四边轮换出现，朝小人当前身体位置飞来，尖端与飞行方向一致，碰撞也使用旋转后的尖端位置。节奏循环为单发突袭、相对两侧错时夹击、同侧三连追击；每个攻击先在边缘预警至少 0.75 秒，连发错开 0.4 秒。纸飞机在飞行前 1.1 秒内有限度追踪头部，其余物品维持预告方向。速度按距离和波次控制，避免宽屏侧向攻击过慢；视口缩放同步更新生成边界。

防护中心改为身体节点的平均位置，支持保护头部、身体和下方。表情平时跟随原有动作逻辑，接近危险时凝视、击退时自信微笑、受伤时嘟嘴、气量低时勉强露齿、蓄力时星星眼、清场时闪亮露齿，结束后躺平。事件表情有短暂保持时间；暂停冻结表情。

底部左右脚蹬按钮、模拟说明卡片及顶部模拟选择器均移除。必杀进度不再常驻：未解锁隐藏，刚解锁显示 3 秒，之后只在实际蓄力时出现，清场/暂停/结束时隐藏。提示文字也会自动消失。
