# 充气打工人 · Air Worker

## 主题皮肤

新增「摸鱼」「顺气」「散班味」「续命」「放风」五套参考图主题，使用 imagegen 生成的透明道具图集。摸鱼搭配鱼缸、小鱼、水草、潜水镜和气泡；顺气搭配软垫、保温杯、杯垫、颈枕、手持热饮、盆栽和微风；散班味搭配折扇、工牌、疲惫云与清新气流；续命搭配茶杯、茶包、蒸汽和茶碟；放风搭配拱窗、风筝、线轴、围巾、邮差包、云朵、树叶与风线。

贴图佩戴修订：摸鱼移除毛巾，鱼和海草使用局部 UV 微动态（暂停与减少动态设置均生效）；顺气新增浅蓝颈枕与手持热饮，壶底与杯垫绑定同一屏幕锚点。续命的茶碟对齐杯底、茶包线固定在杯沿。放风围巾在颈部按前后两层环绕，邮差包以左前臂为支点，让手臂穿过包带；配件不再作为一个整体悬浮在身前。新增素材和提示词记录于 `relax-accessories-imagegen.txt`。

顺气颈枕更新为正面、低矮环绕的 v2 贴图，宽开口对齐肩颈，短圆前端靠拢在下巴下方。颈枕在泄气时保留蓬松体积，前后层按新开口分离。生成提示词见 `relax-neck-pillow-v2-imagegen.txt`。

模型页右侧的「主题皮肤」、游戏页左下角的皮肤菜单，以及桌宠右键菜单均可切换。选择「原始小人」可收起全部装饰；刷新后记住选择。主题保留主体网格和原版外观。潜水镜与工牌跟随身体，折扇跟随右手，轻微漂浮随暂停冻结。游戏过程中切换主题会暂停，点击继续即可恢复。

主题道具是面向相机的透明插画装饰，不是替换角色的三维模型；仅用于实时显示，不包含在角色 GLB 导出中。素材及生成提示词见 THEME_SKINS.md。

鱼缸和杯子使用「后沿 / 液面 → 原角色 → 前壁」的分层关系，角色位于容器内部，后沿不会横穿身体；前后图层在透视视角下保持对齐。放风围巾与邮差包跟随身体，线轴跟随右手，风筝线实时连接线轴与风筝。打开 `http://127.0.0.1:5187/?theme=wind` 可直接预览放风，其他主题参数为 `fishing` / `breathe` / `fresh` / `tea`。

鱼缸与咖啡杯加入屏幕轮廓碰撞：加载时从贴图透明通道采样外壁，结合标注的开口和底部形成空心碰撞轮廓。身体和手臂以投影后的圆形截面近似，使用连续扫掠检测阻止快速穿墙，并在原有 120 Hz 物理步进里处理支撑、滑动、摩擦和轻微回弹。相机旋转、透视和桌宠缩放都使用相同的图像坐标映射；前壁遮挡不作为实心障碍。切换其他主题即移除容器碰撞，暂停时不继续计算。

稳定性修订：容器接触约束进入身体和手臂的求解迭代，最后只重建一次速度；限制单步可见位移并扩展碰撞余量。容器主题使用浅景深活动范围及有间隔的轻推，替代强行设置躲避姿势，减少缸沿抖动、突然弹跳和深度折叠导致的穿插。原始小人和其他主题保留原有运动。

泄气静止与回正：容器内的小人完全泄气并接触支撑后，逐步衰减身体、手臂的约束位移，随后进入静止状态，避免不断蠕动。重新充气会立即唤醒，并以受碰撞约束的渐进回正帮助身体从折叠姿势站起。回归测试使用当前鱼缸贴图采样轮廓与尺寸，覆盖桌宠正面、网页透视以及重复泄气 / 气少 / 气多循环。

选择「摸鱼」或「续命」后点击「碰撞演示 · 晃一下」，或使用桌宠右键「鱼缸 / 咖啡杯碰撞演示」观察左右摆动接触；切换没气 / 气多可观察倒下与恢复。这是面向当前视角的二维近似碰撞，不是三维容器或流体模拟；其他主题的道具继续使用原插画装饰。`sprite-collision.test.mjs` 覆盖透明玻璃轮廓、开口、缸沿承托、高速穿越、透视投影、泄气恢复及不同刷新率。

## 角色外观

桌宠与模型预览固定使用原版衣服和淡定表情，不再提供自定义形象、拍照演示、换表情、随动作切换表情或换衣服入口，也不读取旧的个性化选择。主题道具仍可切换并记住选择。游戏中的动作表情和专注状态反馈继续保留。

短胖的充气上班族，保留无打光色块、短手臂和慵懒表情。

## 实时模拟
预览通过 physics.js 的固定 120 Hz 位置约束求解器计算动作：25 个身体节点、两条独立手臂、重力、惯性阻尼、送风推力、随压力变化的弯曲刚度、底部到顶部的压力传输、折弯压力损失、地面接触。相关随机扰动使摆动不再固定循环。

三种状态直接改变送风量。切换不重置位置或速度：没气缓慢泄压并逐渐软塌，气少支撑较弱，气多恢复鼓胀并摆动。暂停和调速对所有状态有效，底部进度条显示顶部压力。

这是为交互效果设计的简化弹性杆和气压模型，参数为视觉调校，尚未用实物数据标定，不是完整流固耦合或布料求解。极端折叠仍可能自交。

## 交付
- model.mjs：角色几何；预览使用 rest 模式生成静止网格，旧曲线代码仅保留供历史参考。
- arm-mesh.js：每条手臂与手掌使用一张连续网格、共享法线，仅以顶点色区分袖子和皮肤；弯曲方向连续插值。
- physics.js：实时动力学与网格变形。
- toon.js：不受灯光影响的色块。
- silhouette.js：基于整个角色遮罩的屏幕空间外轮廓，保留粗描边，避免膨胀背面在手腕和折弯处露出黑线。描边属于预览效果，不烘焙到 GLB。
- public/air-dancer.glb、air-dancer-low.glb：分别为气多、气少模拟的 6 秒动作采样（不是无缝循环，也不携带实时求解器）。
- public/air-dancer-none.glb：关风后稳定下来的姿态。
- dist/：已构建的预览；GLB 使用 KHR_materials_unlit。

## 运行
npm install 后运行 npm run dev。npm run model 重新采样并导出三个 GLB，npm run build 构建预览。npm test 检查手臂网格连通性、接缝与法线，以及状态切换连续性、关风落地、重新充气与稳定性。

已安装 Node.js 可双击 start-preview.cmd，或 node preview.cjs 后打开 http://127.0.0.1:5187/ 。使用本地 HTTP 服务访问，不能直接双击 dist/index.html。

## Windows 桌宠
双击 start-pet.cmd，或运行 npm run pet。首次使用先 npm install；启动后无需本地网页服务器。透明无边框窗口默认置顶，右键「桌宠大小」可选择 50%、75%、100%、125%、150% 并记住上次选择；窗口同步调整并保持在屏幕工作区内。角色按所选比例显示，禁用桌宠窗口最大化、全屏和页面快捷缩放，左键拖动，右键切换气量、主题皮肤、桌宠大小、暂停和退出。鼠标朝桌宠靠近时，它会侧弯躲一下，再继续摆动。固定正面正交视角，身体与手臂允许三维运动，前后受力较弱，放气更偏向左右倒下。npm run pet:start 直接运行已构建版本。网页预览仍可自由旋转。

## 脚蹬互动
左 A、右 L；按住接通、松开断开。双脚满气、单脚半气、离座没气。桌宠通过全局键盘钩子接收 A/L（不记录其他按键），在其他软件前台时同样响应；普通键盘 A/L 也会触发，可在右键菜单关闭脚蹬控制。网页仅在页面有焦点时响应。单次踩踏带来轻微侧向回弹。屏幕不显示 A/L 控件或文字气泡；倒下时按实际头部速度绘制黑白斜线，落地短暂出现无文字的冲击折线，暂停时冻结。

## 交替蓄力与专注
连续交替踩 A/L（相邻踩下间隔小于 1.5 秒）约 10 次蓄满，长按重复与同侧重复不累计。停顿逐渐退回。蓄满进入 15 秒超级模式，满气与黑白漫画周边排线，当前前台应用窗口去掉边框并铺满所在屏幕，桌宠维持原尺寸；Esc 可随时恢复，也会自动结束。不更改系统通知免打扰设置。倒下时皮肤按高度渐变青绿，仅没气与其他状态切换过程中背后出现漫画斜线；起身恢复肤色。

桌面全屏通过 focus-window.ps1 保存并恢复前台窗口样式与位置，支持 Esc、15 秒结束及正常退出恢复。

专注模式仅叠加 imagegen 生成的黑白漫画周边排线与网点素材，保持原模型、衣服、表情与实时动作。移除金色能量与电光，左右脚使用 A/L。

专注模式表情为 imagegen 生成的透明五官贴图，仅更换五官，不遮盖肤色、不更换模型。退出恢复之前表情；自动表情模式也可正常恢复。

速度线减少为 12 条，沿头部实际运动反方向拖尾，长度随速度变化。专注模式增强气流支撑与抗弯刚度，头后出现放射线。蓄力条采用生图生成的漫画墨线边框与动态排线填充。全屏助手使用独立输入队列，记住最近外部窗口，并恢复原位置、大小与最大化状态。

放射线每 700ms 采样角色周围屏幕明暗，深色背景切换浅线、浅色背景切换深线。采样仅用于亮度计算，不保存或上传屏幕内容。前台铺满使用物理像素 DPI 感知并清除窗口最大化/边框约束，回读实际窗口尺寸供诊断。

速度线保持 45 度，按左右运动方向镜像。漫画蓄力条跟随头顶投影并限制在窗口内；专注入场出现一次向外扩散的冲击环，头后大气泡持续到专注结束。

专注入场的扩散环通过独立透明置顶效果窗口覆盖角色所在整个屏幕，约 2.2 秒自动关闭，不抢焦点、不拦截鼠标。速度线仅在没气切换过程且实际下坠时出现，起身不显示。

专注模式使用 imagegen 生成的透明黑白漫画图集，使用尖角爆炸、闪电冲击和放射气泡三种样式。每次进入专注，在头后弹出一个大气泡并持续跟随头部，相邻两次选择不同样式。额头、脸侧、脸颊、衣领和身体侧面出现漫画阴影排线，排线随角色弯曲。退出专注会隐藏气泡和阴影。素材位于 public/focus-comic-atlas.png。

没气状态下忽略鼠标躲闪，重新充气且顶部气压达到 25% 后恢复互动。鼠标靠近时，桌宠在约 0.16 秒内向左或向右弯成旋转 90 度的横向 U 字，中段鼓出，头部在上方向开口侧回勾，到位后立即释放给气压、弹性、重力与惯性模拟，从被扰动后的姿态自然恢复和摆动。恢复速度取决于当前气量。底座固定，手臂跟随身体弯折。

专注皮肤采用 imagegen 生成的透明面部与衣服阴影贴图，包含严肃眉眼、鼻梁和脸颊排线。脸侧、身体侧面、袖子下缘、手臂和圆手掌的轮廓阴影根据实际模型表面方向分布，与原网格共享变形。新生成的墨线按身体、手臂和手掌的曲面坐标包裹，并按轮廓方向控制阴影浓度。退出专注恢复原表情并隐藏阴影。素材为 public/focus-expression-ink-v3.png 和 public/focus-contour-ink-v3.png。

## 沉浸式游玩：工作间隙

分支 feat/immersive-pedal-play。双击 start-play.cmd 自动启动本地服务并打开 http://127.0.0.1:5190/play.html 。也可运行 node play-preview.cjs。npm run dev 开发，npm run build 同时构建原模型页和游玩页。

背景保留低饱和底色和细颗粒肌理，边缘加入生图制作的排线办公桌、椅子、文件柜和打印机，不构建完整房间。角色沿用原模型、服装与动态表情，攻击物统一为一套带尖角的抽象工作符号：邮件、绩效箭头、截止时钟、会议对话、加班月牙和鼠标光标；去掉具象设备和复杂文字细节。物品仅从上、左、右三侧出现；左脚的物品固定从左侧或左上方来，右脚的物品固定从右侧或右上方来，不交叉。

### 双脚动作与到线判定

左脚 W/S/A/D 对应前(↑)/后(↓)/左(←)/右(→)，Q 旋转。右脚 I/K/J/L 对应前/后/左/右，U 旋转。物品上标记动作及要求的左脚或右脚；顶部不再显示提示气泡或动作预告。旋转当前使用按键替代，不需要鼠标画圈。

以小人全身中心的细圆环作为判定线。物品中心到线时，按正确脚的正确动作才会格挡：时差 ±0.15 秒为 PERFECT（20 分），±0.4 秒内为 GOOD（10 分）。长按不重复触发，提前输入不能预先架盾。到线窗口内按错脚或动作会使该音符失败；漏拍打断连击，物品继续进入圆环，造成 28% 漏气。当前试玩模式气量耗尽也不结束，每次成功格挡补 3% 气量。

动作序列包含前后左右和旋转，左右脚交替。每件物品预留 3.6 秒到线时间，初始间隔 1.25 秒，随波次缓慢加快，最快间隔 0.9 秒。旋转前后各多留一个节拍。画面有短暂的 PERFECT/GOOD/MISS 和连击反馈，表情根据成功、受击、蓄力、清场变化。P/Esc 暂停，切换窗口自动暂停并释放输入。

### 攻击大爆发与双脚蓄力

取消击退数量解锁和单键空格清场。开局第 18 秒出现第一次大爆发，先预警 2 秒，再由 24 件物品从上、左、右围攻；普通动作判定暂停。10 秒内交替踩踏左右脚 12 次释放必杀，清场补气 20%。结束后间隔 26 秒再出现下一次大爆发。

键盘 F / H 分别模拟左 / 右脚踩踏，必须按下并松开后交替；长按、单边连按、同一帧同时按两边不能完成蓄力。停顿超过 1.5 秒开始退蓄力。普通方向键仍使用 W/S/A/D 和 I/K/J/L，Q/U 旋转。鼠标仍只模拟单脚，不能独自清场。空格仅用于开始或继续。

超时围攻会造成 56% 漏气，保留不死亡试玩模式。事件期间显示临时蓄力条、剩余时间和下一只脚提示，结束立即隐藏。普通格挡不再积攒必杀。

### 手柄和硬件

标准 Gamepad 左/右摇杆量化为对应脚的四个方向，达到0.6阈值触发一次，再回到0.25内的中位才能重触发；斜向不作为动作。LB/RB 模拟左右旋转，LT/RT 模拟必杀踩踏。

window.airWorkerGame.perform(action, side) 接收 up/down/left/right/rotate 及 left/right；setStick(side,x,y,down) 提供轴与踩踏开关；setPedal(side,down) 只控制踩踏。旋转硬件可调用 perform('rotate',side)。当前尚未连接真实脚蹬。

自动测试覆盖三侧生成、全动作覆盖、到线位置和时间一致、正确脚/动作、PERFECT/GOOD窗口、提前不预存、按错不能补救、漏拍漏气、连击、清场和表情优先级。生产构建通过。浏览器视觉验证受此前本地地址权限拒绝限制，本轮未进行画面实测。

当前默认开启不死亡试玩模式：受击仍漏气和变化表情，气量降到 0 也不结束，可继续跟拍并通过成功格挡补气。

游玩页不显示品牌或主题标题，上方居中的横向积分条展示活动积分、波次、气量与个人最佳；进入时直接显示游玩场景和计分卡。命中、格挡或清场后的攻击物直接消失，保留短促反馈，不再反弹。

### 界面参考与配色

参考金匠官方取号界面（https://www.kinsho.com/nd.jsp?id=57）、官网漫画海报（https://www.kinsho.com/）和米吉卡品牌案例（https://mijika.cn/index.php/kdkf/260.html）的粗描边、暖色块与漫画标签。界面采用奶白 / 麦黄 / 炭黑与轻微错位的实色阴影。UI、判定线、粒子和进度条均去掉绿色。参考图仅供研究，未打包进游戏。
